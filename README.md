# 🌍 Traveloop

Traveloop is a modern travel management web application that helps users explore destinations, plan trips, manage itineraries, and track travel statistics — all in one place.

Built with a clean UI and responsive design, Traveloop focuses on creating a smooth and interactive travel planning experience.

---

## ✨ Features

- 🧭 Interactive Dashboard
- 🌎 Explore Multiple Countries & Destinations
- 📌 Create and Manage Trips
- 📊 Travel Statistics Cards
- 🗂 Responsive Sidebar Navigation
- 🔍 Destination Search Functionality
- 🎨 Modern UI using Tailwind CSS
- ⚡ Fast and Responsive React Application

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM

### Tools & Libraries
- Vite
- Hero Icons / Lucide React
- Git & GitHub
